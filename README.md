# doc-publisher

Публикует документацию проекта в Docmost по файлу `docmost.yaml`.

```
uv run tools/publish.py --root <проект>
```

Источник правды это файлы проекта: публикация заменяет все страницы пространства, правки и комментарии в Docmost теряются. Данные для входа берутся из файла `credentials` или из `DOCMOST_EMAIL` и `DOCMOST_PASSWORD`.

Запланировано: страницы C4 и реестры из YAML, панель готовности, ссылки между страницами, обновление вместо замены.
